# 기능 명세 반영: 2026-09-20

원본: https://app.notion.com/p/3d034c4d3a7b801db47bdce4752c2197

Notion 연결 도구에서는 접근할 수 없어 사용자가 열어 둔 데이터베이스 화면에서 요구사항을 확인했다.

이번 범위:
- F-005: 제품명·브랜드·분류 검색에 분류 필터, 다중 검색어, 결과 수, 초기화 제공.
- F-018: 현재 식단의 제품 하나를 가상 제외하고 전후 영양소 총량·상태·변동량 동시 표시. 실제 식단을 변경하거나 비활성 카탈로그 제품을 추가하지 않음.
- F-020: 현재 식단 및 가상 제외 식단의 월 예상 비용 비교와 일일·월간 제품별 비용 표시. 대체 제품 추천 조합 비교는 이번 범위에 포함하지 않음.

검증 기준:
- 검색어와 분류 필터를 동시에 적용하고 초기화할 수 있다.
- 비교 중 원래 급여량·활성 상태는 보존된다.
- 제외 제품을 바꾸거나 급여량을 바꾸면 이전 응답을 최신 결과로 표시하지 않는다.
- 누락된 영양소는 0으로 해석하지 않고 정보 부족으로 표시한다.
- 가격 누락은 부분 합계임을 알리고 유효하지 않은 기준량으로 나누지 않는다.
- 실패 시 재시도할 수 있다.

실행: `node --test tests/comparison.test.mjs`, `npm run build`.

공식 영양 기준, 실제 상품·가격 수집, 저장·복원, OCR, 리포트 등 나머지 항목은 이 변경에서 완료한 것으로 간주하지 않는다.
